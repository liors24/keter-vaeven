# כתר ואבן

**לשחק עכשיו:** https://liors24.github.io/keter-vaeven/

משחק בניית טירות ימי־ביניימי בתלת־ממד שרץ בדפדפן: מחשב, אייפון ואנדרואיד, כולל מסך מלא.

- בנייה חופשית מ־20 חומרים (אבן, בזלת, שיש, לבנים, עץ, קש, רעפים, ויטראז׳, זהב ועוד), חומות, מגדלים, מצודות ושערים
- מבנים שמכניסים זהב (חווה, שוק, קתדרלה) ומבנים לגיוס צבא (קסרקטין, אורווה)
- גיבור שנכנס לטירות, מטפס במדרגות ונלחם, וצבא עם פקודות
- 13 יעדים לכיבוש בעולם פתוח: מאהלי שודדים, מבצרים וטירות אויב
- יצירת ממלכה עם שם ודגל משלכם (צבעים, דוגמאות וסמלים)
- שמירה אוטומטית בדפדפן

## הרצה מקומית

```
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000

## פרסום חינמי

האתר מתפרסם מ־GitHub Pages ישירות מהענף main, וכל דחיפה מעדכנת אותו.
הגדרה חד־פעמית: Settings ← Pages ← Source: **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`.
